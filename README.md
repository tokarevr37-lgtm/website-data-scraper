# Website Data Scraper

Python scraper for collecting website data and exporting it into CSV format.

## Features

- Collects product data from a website
- Extracts titles, prices, and availability
- Exports clean structured data into CSV
- Uses BeautifulSoup and Requests
- Simple and easy to customize

## Technologies

- Python
- BeautifulSoup
- Requests
- CSV

## Example Output

| Title | Price | Availability |
|---|---|---|
| Book 1 | £51.77 | In stock |
| Book 2 | £45.17 | In stock |

## Installation

```bash
pip install requests beautifulsoup4
```

## Run the Script

```bash
python scraper.py
```
